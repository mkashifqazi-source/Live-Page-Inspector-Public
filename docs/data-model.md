# Evidence contracts and source ownership

The logical result carries requested URL, mode, retrieval time, network observations, initial HTML, rendered DOM, differences, extraction status, warnings/content-safety metadata and safe errors. FAST leaves rendered evidence not requested. Rendered failure must not relabel initial HTML as rendered success.

Network evidence owns HTTP status/final URL/redirect chain and selected bounded response metadata. Initial HTML owns its document URL and parsed tags/text. Rendered DOM owns the captured browser URL and DOM/text. A canonical's raw value, resolved value, source and multiplicity are separate; conflicting directives/tags remain inspectable.

Newer additive contracts carry schema version, evidence/derived sections, state, warnings and explicit availability/completeness. Available, not requested, not available and not applicable are different meanings. Null/unmeasured counts differ from measured zero; observed/analyzed/returned counts and lower-bound/truncation markers prevent an output cap from looking like complete enumeration.

Page-contract and resource-contract versions are separate from package/server versions. Legacy projection excludes additive contracts to preserve compatibility. An additive field's existence does not prove all later analysis phases are complete or deployed.

Resource outputs distinguish typed response/MIME/compression evidence, structured robots/sitemap data and bounded traversal. Page analysis preserves source-specific URL/directive/link/content semantics. Pending diagnostics analyze captured JSON-LD/date/hreflang evidence without claiming a platform winner, fetching alternate targets or proving reciprocity.

A local noindex or canonical observation is evidence relevant to eligibility. It is not a Google-indexed verdict, a rich-result appearance guarantee or proof of what a search crawler received.
